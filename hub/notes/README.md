# Notes

Free-form notes, sketches and plans that are not polished docs yet. Create one with **+ New note** in the hub.
Attach diagrams/photos with **Attach files** (saved in `hub/files/`) and link them like `![wiring](../files/wiring.png)`.

When a note becomes a decision or a finished doc, move it into `docs/` or `ai-instructions/WORKING_NOTES.md`.
