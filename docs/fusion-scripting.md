# Fusion scripting

All printed geometry is generated by Python scripts that run inside Autodesk Fusion. The model is rebuilt from code. Do not hand-edit it.

## Generators
| Script | Builds | Notes |
|---|---|---|
| `fusion/SENNEP_WheelGenerator/SENNEP_WheelGenerator.py` | "11 Wheel Lab" (wheel, axle, spacer, rollers), "11 Wheel Lab Testprint (hurtigtest)" | Parameters `Wheel_*`, `Axle_*`, `Spacer_*`, `Motor_*`. Call `build()`. |
| `fusion/SENNEP_WheelGenerator/assembly_ring.py` | "11 Wheel Lab Assembly Ring (samlering)" | `build_ring()`. Variants with and without TPU sleeves. |
| `fusion/SENNEP_ChassisGenerator/SENNEP_ChassisGenerator.py` | `build_pod()` → "21 Pod Lab" (housing), `make_hollow` → hollow variant, `build_chassis()` → "20 Chassis", `build_battery()` → "31 Battery Module" + "32 Battery Mount", `build_hardware_library()` → "90 Hardware", `build_test_print()` → "93 Test Print", `build_body()` → "50 Shell" | Parameters `Chassis_*`, `Brg_*`, `Mot_*`, `Frame_*`, `Shell_*`; printed-bolt constants in `PM8`. |
| `fusion/SENNEP_ChassisGenerator/pod_hardware.py` | "22 Pod Lab Hardware", "23 Pod Lab Skruetraekkere bagfra" | Screws, washers, inserts and tool clearance for the housing. |

Fusion document: **"SENNEP V2"**. "Robot v58/v59" are the old models, read-only.

**Coordinates:** origin = middle of the footprint on the floor, **front = −Y**, left = −X, up = +Z. The wheel frame has X = wheel axis (+X towards the motor).

**Component numbering:** 00 Layout · 10 Drive · 11 Wheel Lab · 20 Chassis · 21–23 Pod Lab · 30 Electronics (31–32 battery) · 40 Sensors · 50 Shell · 90–93 hardware and test prints.

## Recipe (every generator)
- Parameters in a `PARAMS` dict that become Fusion user parameters (created on first run, edited in *Modify → Change Parameters*).
- The component is rebuilt in place. Geometry is made with `TemporaryBRepManager` and base features.
- Fillets go through a "try" helper that reports whether each one succeeded.
- Automatic checks on every run: collisions, clearances, overhang faces (normals sampled on every face, cylinders included), parts under the floor, parts larger than the 220 mm plate.
- STL export goes to `print/<name>/` with a `LÆS MIG.md` (orientation, assembly, what to test). Since v3.1, STLs are pre-rotated to print orientation (print face on Z = 0).

## MCP usage
- Locally, Fusion exposes an MCP server at `http://127.0.0.1:27182/mcp` (Fusion → Preferences → General → API → Fusion MCP Server). In claude.ai it appears as the **Autodesk_Fusion** connector (`fusion_mcp_execute`, `featureType: script`).
- **Cloud sessions cannot reach Fusion.** A tunnel is discouraged, because it would allow unauthenticated remote execution of arbitrary Python.
- Scripts must define `def run(context)`. Over MCP: `exec` the file and call `build()`. `run()` shows a message box and must not be used.
- **One build per MCP call.** Two builds in one call timed out. 75 single unions also timed out (>10 min); doubling (7 unions) plus one rotated cutter took ~1 min.
- Scripts cannot run while a dialog is open in Fusion.
- Client-side HTTP timeouts can happen even though Fusion finished the job. Verify the model state afterwards instead of trusting the timeout.
- When the connector would not reconnect, a small HTTP client calling the endpoint directly worked.

## Pitfalls
- Changing a user parameter or adding an occurrence **resets transform overrides** on proxy occurrences. Set parameters first, add every occurrence, place them last. For display, use body **copies** instead of nested occurrences.
- Nested occurrences only move via `createForAssemblyContext(...).transform2`. `moveToComponent` resets the transform.
- Joints and motion links must be deleted before a rebuild. Delete base features before bodies.
- Body names and appearances set after `finishEdit()` are lost when another base feature recomputes. Set appearances **inside** `startEdit/finishEdit`, and set names after `finishEdit` (verify they stuck).
- `SurfaceEvaluator` has no `getParameterExtents`. Use `parametricRange()`.
- The camera's `viewExtents` behaves oddly after an ortho camera. `isFitView = True` works.
- Half-space cutting boxes (`BIG`) must be large: 1000 mm was too small for sloped planes across the robot, and it is now 4000.
- Occurrence bounding boxes include sketches (this is how the wheel was once misread as Ø130 instead of Ø106.2).
- Bash heredocs mangle `\n`. Write patch scripts with a file-writing tool.
