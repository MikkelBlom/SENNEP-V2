# LiDAR stack v2 — benchmark

Machine: Intel(R) Xeon(R) Processor @ 2.80GHz (x86_64), 4 cores. Build: release. Generated by `cargo run --release --bin bench`.

> **Not measured on the Pi.** The Pi 5 (Cortex-A76) is expected to be about 1.5–2.5× slower per core than this machine. Run `bench` on the Pi for the real numbers (see `lidar/README.md`).

All sources are replayed as fast as possible; only the pipeline (parser → zones → scan assembly → filter → odometry → map) is timed.
*CPU* = CPU time / data duration, i.e. how large a share of one core the stack uses in real time.
*Per packet* = parser + zone update for 12 points (what the safety zones wait for). *Per revolution* = filter + odometry + map, after the revolution's last point.
